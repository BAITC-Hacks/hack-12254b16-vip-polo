## Сохранность и ограничения

Simulation/data совпадают с SHA PR №2, серверный AI и api/analysis — с PR №4. Shared, fixtures, пакетные версии и lockfile сохранены. Бюджет 100, north/center/south, пять направлений, model-v1/synthetic-v1 и контрольные числа не менялись. Runtime не импортирует fixtures и не использует фиктивные успешные ответы. AI остаётся server-only.

AI-настройки и локальный .env.local в проверяемой копии отсутствуют. Настоящий ответ провайдера и его смысловая корректность не подтверждены. Fallback обозначен в интерфейсе и не считается реальным AI.

GitHub Actions раньше не запускал шаги из-за блокировки оплаты организации. Статус для окончательного SHA требуется читать отдельно в PR/Actions; failure инфраструктуры не считается успешным CI. Финальный внешний отчёт фиксирует текущий статус и merge SHA.
