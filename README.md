# Аким на 5 часов

Hackathon team repository for VIP POLO.

Браузерная учебная модель управления условным городом. Пять решений при общем бюджете должны приводить к Astana Quality of Life Score и AI-объяснению. Данные синтетические; результат не является официальной оценкой Астаны или рекомендацией акимату.

## Текущее состояние

Реализован **нулевой этап**: запускаемая стартовая страница, общие типы и схемы, канонизация сценария, исходные JSON, тестовые примеры и окружение для трёх участников. Игра, расчётная модель и AI пока не реализованы. POST /api/simulate и /api/analysis возвращают HTTP 501 с code=NOT_IMPLEMENTED. Полного прохождения пока нет.

## Установка и запуск

Нужны Node.js **24.19.0**, pnpm **11.19.0** и доступ к npm при установке. Версия Node — в .node-version, pnpm — в packageManager. Установите эти версии своим менеджером среды; системные пути компьютера автора не нужны.

```sh
git clone https://github.com/BAITC-Hacks/hack-12254b16-vip-polo.git
cd hack-12254b16-vip-polo
# Пока PR каркаса не объединён:
git switch chore/scaffold
node --version
pnpm --version
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://localhost:3000. Ожидаются заголовок «Аким на 5 часов», бюджет 100 условных единиц, три района, пять направлений и явное сообщение о неготовности полного прохождения. Для другого порта: `pnpm dev --port 3001`.

После merge каркаса используйте актуальную main вместо chore/scaffold; каждый участник создаёт свою ветку и копию.

Production-запуск:

```sh
pnpm build
pnpm start
```

Сборка не загружает внешние шрифты и не требует AI-ключа.

## Проверки

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

На Linux для браузера может понадобиться `pnpm exec playwright install --with-deps chromium`. E2E сам запускает production-сервер на 127.0.0.1:3100; порт должен быть свободен. Vitest проверяет схемы, JSON, fixtures, ID, страницу и явные заглушки. Полная симуляция этими тестами не подтверждается.

`pnpm test:ai-live` сейчас завершается NOT_IMPLEMENTED с кодом 1: провайдер подключает участник 3. Эта команда не входит в CI и не выдаёт пропуск за успешную live-проверку.

## AI и секреты

При подключении провайдера скопируйте .env.example в .env.local. Серверные переменные: AI_PROVIDER, AI_MODEL, AI_API_KEY, AI_TIMEOUT_MS (15000). Сейчас они не используются. Не добавляйте реальные значения в Git и не переименовывайте ключ в NEXT_PUBLIC. Провайдер и модель пока не выбраны.

## Учебная модель и контрольные примеры

Бюджет 100; три условных района; model-v1/synthetic-v1. Пять индексов 0..100, больше лучше. Планируемый Score — среднее 15 показателей, округление итогового Score до двух знаков. Начальное среднее 50. Это выбор команды, а не официальные параметры организаторов. Правила и исходные числа — docs/contract.md и src/data.

tests/fixtures/scenario-*.json содержит полные запросы и ожидаемые ответы будущей модели:

| Сценарий | Выбор в north | Расход | Ожидаемый Score |
|---|---|---:|---:|
| A | Все basic | 50 | 51.67 |
| B | Как A, transport-premium | 70 | 52.53 |
| C | Все standard | 100 | 53.33 |
| D | Все premium | 150 | BUDGET_EXCEEDED |
| E | A без service | 40 | 51.33 в draft; final отклоняется |

Сейчас эти значения — согласованные ожидаемые ответы, а не результат рабочего API. Проверка стартовых маршрутов после запуска:

```sh
curl -i -X POST http://localhost:3000/api/simulate -H 'Content-Type: application/json' -d '{}'
curl -i -X POST http://localhost:3000/api/analysis -H 'Content-Type: application/json' -d '{}'
```

Ожидается HTTP 501 у обоих. После реализации модулей повтор A должен совпадать численно, A/B различаться, D отклоняться даже прямым POST. Бюджет, финальные пять решений и настоящий AI пока не реализованы.

## Совместная работа

Проверить и объединить PR каркаса; зафиксировать один SHA main; работать в отдельных копиях на feat/game-ui, feat/simulation, feat/ai-analysis. Общие зависимости, контракт и README меняет Талгат. Модули идут отдельными PR; merge подтверждает команда. Затем интеграция и полное прохождение с настоящим AI. Без push прямо в main и force push.
